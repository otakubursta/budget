# Budget

Локально: правый клик по public/index.html → Open with Live Server (данные в браузере).

Облако (Cloudflare Workers + D1):
1. Создайте базу D1 `budget`, выполните schema.sql в Console.
2. Вставьте database_id в wrangler.toml.
3. Подключите репозиторий в Workers & Pages (Deploy command: npx wrangler deploy).
4. Settings -> Variables and secrets -> Secret APP_PASSWORD (логин admin).
5. Domains: включите workers.dev.

## Обновление до v2 (если база уже есть)
1. Сделайте «Экспорт» (JSON) — резервная копия.
2. Выполните `migrations.sql` в D1 Console (добавляет колонки note, type, link; данные не меняются).
   Новый worker.js и сам добавляет эти колонки при первом запросе, так что шаг — подстраховка.
3. Задеплойте новую версию. Старые операции и настройки загрузятся как раньше.

## Что нового в v2
- Быстрый ввод: чипы категорий (частые первыми), «Сегодня / Вчера», строка вида `-12.5 кофе chf`,
  автоподбор категории по описанию, шаблоны в одно нажатие, повтор операции, комментарий.
- Переводы между валютами (USD → CHF): меняют балансы кошельков, но не входят в доходы/расходы.
- Вкладка «Планы»: лимиты по категориям, регулярные операции (создаются сами), шаблоны.
- Overview: прогноз расходов на конец месяца, норма сбережений, прогресс лимитов.
- История: поиск и фильтры. Экспорт в CSV.
- Демо больше не трогает ваши данные (только просмотр). Ошибки сервера — откат + уведомление.
- Клавиши: Enter — сохранить, Esc — отменить редактирование, «/» — к полю суммы.
